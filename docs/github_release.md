# GitHub release checklist

1. Create a public repository named `aqx` (or `adaptive-quant-execution`).
2. Push the `main` branch and verify the CI workflow is green.
3. Add repository topics such as `python`, `quantitative-finance`, `performance`, `numba`, `numpy`, `benchmarking`, and `machine-learning`.
4. Create the `v1.0.0` Git tag and a GitHub Release using the release notes in `CHANGELOG.md`.
5. Add the repository description: `Risk-aware adaptive backend selection for quantitative Python workloads.`
6. Keep the research caveats visible; do not market the benchmark as a production performance guarantee.
7. Invite early users to report their hardware, Python/NumPy/Numba versions, workload, and timing evidence in issues.
